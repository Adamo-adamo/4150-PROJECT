# GradMap Delivery Checklist

- [ ] Public landing page clearly explains GradMap, Career Mode, Master's Application Mode, fictional-data scope, and the primary demo CTA.
- [ ] Demo workspace opens with fictional programme and graduate-role data.
- [ ] User can switch between Career Mode and Master's Application Mode.
- [ ] Dashboard shows in-motion, due-soon, readiness, and shortlist metrics.
- [ ] User can search, filter, sort, select, and open application paths.
- [ ] User can add a path through the application dialog.
- [ ] Application detail shows status, deadline, readiness, requirements, action list, notes, and fictional adviser notes.
- [ ] User can toggle requirement readiness and task completion.
- [ ] User can compare two to four same-mode paths side by side.
- [ ] User can view upcoming deadlines and open a path from the timeline.
- [ ] User can view reusable documents and add a fictional demo document.
- [ ] User can view the read-only adviser review screen.
- [ ] User can export the current mode summary as CSV.
- [ ] User can view the three pricing tiers and complete the test-only upgrade flow.
- [ ] Responsive behavior works on laptop, tablet, and narrow mobile widths.
- [ ] Keyboard focus rings, accessible labels, text status labels, and reduced-motion behavior are present.
- [ ] `pnpm check`, `pnpm test`, and `pnpm build` pass.
- [ ] `/api/health` and `/manus-routes.json` return valid responses.
